# Web2MD Chrome 插件

一键将网页转换为 Markdown 格式

## 安装方法

### 方法1：从 GitHub 安装

1. 克隆仓库：
```bash
git clone https://github.com/xuxiaominger/web2md-chrome-extension.git
```

2. 打开 Chrome 浏览器
3. 访问 `chrome://extensions/`
4. 开启右上角的「开发者模式」
5. 点击「加载已解压的扩展程序」
6. 选择 `web2md-chrome-extension` 文件夹

### 方法2：打包安装

1. 访问 `chrome://extensions/`
2. 点击「打包扩展程序」
3. 选择扩展程序文件夹
4. 生成的 `.crx` 文件可分享给他人

## 使用方法

1. 安装插件后，在 Chrome 右上角点击插件图标
2. 输入框会显示当前页面 URL
3. 点击 🔴 红色「转换」按钮
4. 等待提取完成
5. 点击「复制」按钮复制 Markdown 内容
6. 粘贴到 Obsidian 或其他笔记软件

## 功能特性

- ✅ 支持所有网页
- ✅ 自动提取标题和正文
- ✅ 转换为 Markdown 格式
- ✅ 一键复制
- ✅ 微信公众号、知乎等特殊网站支持
